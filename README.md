# SPACEWARD.

The SPACEWARD. website (gospaceward.com). A static site: `index.html` plus the images in `img/`.

- Pushing to `main` publishes the site (Cloudflare Pages is connected to this repository; no build step).
- `index.html` is the source of truth. Edit it directly.
- Imagery: NASA photographs (Earth, Moon), the NASA Tycho star map, and renders built from NASA surface maps and shape models. The lit Moon and terraformed Mars stages are illustrations.
